# Sistema de Cadastro PHP

## Sobre o projeto

Este projeto consiste em um sistema de cadastro desenvolvido como atividade acadêmica, utilizando PHP, MySQL e CSS.

O objetivo é permitir o cadastro e a consulta de informações por meio de uma interface simples e funcional.

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin

## Funcionalidades

- Inclusão de novos cadastros.
- Consulta geral dos registros.
- Consulta individual de registros.
- Conexão com banco de dados MySQL.

## Estrutura do projeto

```text
Sistema-de-Cadastro-PHP/
├── css/
│   └── estilo.css
├── banco_cadastro.sql
├── conexao.php
├── index.php
├── incluir.php
├── consultar.php
├── consulta_individual.php
└── teste.php
```

## Como executar o projeto

1. Instale o XAMPP.
2. Inicie os serviços Apache e MySQL.
3. Coloque a pasta do projeto dentro de `htdocs`.
4. Acesse o phpMyAdmin pelo navegador.
5. Crie um banco de dados chamado `banco_cadastro`.
6. Importe o arquivo `banco_cadastro.sql`.
7. Confira as configurações de conexão no arquivo `conexao.php`.
8. Acesse o projeto pelo navegador:

`http://localhost/projeto_consulta/`
